# Personal Portfolio — Project 04

## About the Project

This project is a personal portfolio website developed as part of Project 04 at 42 Irbid. It showcases my cybersecurity background, technical skills, professional experience, education, certifications, and achievements.

The website uses a futuristic cybersecurity-inspired design with neon cyan and purple colors, a dark background, and responsive layouts.

## Features

- Personal introduction and profile section.
- Technical skills and cybersecurity tools.
- Professional experience and training.
- Projects and practical cybersecurity work.
- Courses, certifications, and education.
- CTF competitions and achievements.
- Contact information and contact form.
- Interactive theme switcher using JavaScript.
- Responsive design for desktop, tablet, and mobile screens.

## Technologies Used

- **HTML5:** Semantic page structure and content.
- **CSS3:** Styling, Flexbox, CSS Grid, animations, and responsive design.
- **JavaScript:** DOM manipulation and interactive theme switching.
- **Git:** Version control.

## Project Structure

```text
Portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   └── profile.jpg
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Navigate to the `Portfolio` directory.
3. Make sure the profile image is placed inside the `assets` directory.
4. Open `index.html` in a web browser.

No additional installation is required.
